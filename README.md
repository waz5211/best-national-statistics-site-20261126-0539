Singapore in Figures is an original national statistics site for Singapore: an overview dashboard with a searchable indicator index, plus pages for population, economy, labour and income, prices, health, education, housing and trade — each with hand-drawn SVG charts, sortable tables and real figures labelled with their source and year, all in plain static files that work fully offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
